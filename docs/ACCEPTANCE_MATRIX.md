# Acceptance matrix — fixture K7 theo [planning_update.md §13](../planning_update.md)

**Source checkout, chưa publish/install; K0–K7 vẫn mở.** Tài liệu này ánh xạ 22 fixture scenario bắt buộc của §13.1 và 7 điều kiện “không đạt” của §13.3
tới test thật. Nó chứng minh **cơ chế** (inert fixtures), không chứng minh pentest hiệu quả, phát hiện đúng bug hay chất lượng finding.
Mọi tham chiếu dạng `<tệp>.test.ts :: <tên test>` bên dưới (đặt trong dấu backtick) được `tests/minimal/acceptance-matrix.test.ts` kiểm tra tự động: đổi tên/xóa test mà không sửa ma trận sẽ làm test này fail.

Nhãn bằng chứng: **U** unit/inert; **R** runtime thật (SQLite + Unix broker + executor inert); **N** actual Pi inert provider (`vitest`, không model trả phí);
**D** opt-in Docker (`P2O_TEST_DOCKER=1`, ảnh sandbox đã có sẵn, không pull). `[mới]` = test thêm cùng slice với ma trận để lấp khoảng trống đã phát hiện.

## §13.3 — Không đạt acceptance nếu…

| Điều kiện không đạt | Bằng chứng chặn |
|---|---|
| Có graph nhưng không trả lời được “task nào chưa review, vì sao blocked, output ở đâu” | `visibility.test.ts :: reported handoff remains awaiting review, not a verified finding or completed goal`; `visibility.test.ts :: status/tasks/log/report never consume Planner signals, call a model or execute target work` |
| Checkpoint chỉ là model summary, không snapshot/version/refs | `assessment-store.test.ts :: captures a transaction-boundary checkpoint, pending review/gaps/in-flight work, and snapshot+tail without duplicating on retry`; `context.test.ts :: rebuilds the same deterministic hot index/cursors from a checkpoint plus contiguous canonical event tail` |
| Finish xóa toàn bộ result mà user tưởng đã lưu | `workspace-runtime.test.ts :: keeps durable knowledge/checkpoints but destroys control/tickets, and opens without an Engine/model/target`; `workspace-runtime.test.ts :: ephemeral uses the same canonical services in-run but deletes knowledge and warns at consent` |
| Graph data bị coi là authorization hoặc replay history tự chạy lại request | `workspace-runtime.test.ts :: records and reads the typed asset graph through owner/worker tools with role limits and idempotent replay`; `graph.test.ts :: returns original ACKs for an identical authenticated batch and conflicts on a changed one` |
| Mọi `confirmed` lên badge verified, hoặc “100% coverage” dựa trên touched assets | `cases.test.ts :: keeps Worker claims pending until an explicit owner revision accepts exact current support`; `coverage.test.ts :: never turns blocked or untested work into clean/accepted coverage` |
| Dedup suppress validator/retest hoặc merge hai bug chỉ vì cùng CWE/title | `work.test.ts :: requires separate validation attempts and retest reasons while retaining discovery history`; `cases.test.ts :: does not merge uncertain or mismatched root causes; accepted duplicates point to one current canonical case` |
| Thêm background LLM hoặc đổi budget/mode mà confirmation không nói | `workspace-runtime.test.ts :: always confirms retention/location/sensitivity before creating durable knowledge or resources`; `extension.test.ts :: confirms once, names the delegation budget, and hands the task to the current agent`; `context-runtime.test.ts :: does not ACK at agent_start or provider-error; a successful response advances only delivery` |

## Chưa nằm trong ma trận này (không suy ra từ các hàng trên)

- **§13.2 measurements** là tài liệu riêng: [store 10k/100k](STATE_STORE.md#reproduce-và-kết-quả-source-qualification), [context packets](CONTEXT_PACKETS.md#verification-scope), [status/widget path](CONTEXT_PACKETS.md#legacy-status-and-widget-path), [graph 4000 assets](ASSET_GRAPH.md). Corpus synthetic, một máy; không phải performance guarantee.
- **Hiệu quả pentest, finding correctness, gap recall, false-suppression rate** cần benchmark có ủy quyền, cùng model/scope/budget, lặp lại và adjudication độc lập (§13.2); chưa thực hiện.
- **Real Herdr** (`npm run test:herdr`, mở/đóng pane trong session đang dùng), **installed-package/managed-Pi acceptance**, provider thật/trả phí: chưa chạy; cần quyết định riêng.
- Fuzzy/semantic dedup suggestion, typed branch-output review, affected-variant policy (K4/K5 còn mở) và segmented archive >64 MiB (K2/K6) chưa có fixture vì chưa có tính năng.
- Mức “Covered” nghĩa là có test cơ chế tương ứng đang pass trên source checkout này; không phải cam kết bao phủ mọi biến thể hay mọi nền tảng.
