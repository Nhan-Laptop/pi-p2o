# Inert reconnaissance source fixture

Only offline source review and benign function calls are intended. There is no web server or live deployment.

The route registry supplies a public health route, tenant-bound order reads and an export enqueue path.
The queue consumer uses a service principal; a request principal must not be assumed to execute it.
Deployment configuration, identity establishment, framework middleware and Git history are not supplied.
Source route declarations do not establish exposure or authorize HTTP requests, including POST.
